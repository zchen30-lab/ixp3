# 📺 Retro TV Remote Game

An interactive retro CRT television experience with channel-switching animations. Click the remote button to cycle through different channels until the TV explodes!

## 🎮 How to Play

1. Open `index.html` in a web browser
2. Click the red button on the remote control to turn on the TV
3. Keep clicking to switch channels:
   - **Channel 0**: TV Off (static noise)
   - **Channel 1**: Pixel Boxing Championship - Watch two pixel boxers duke it out!
   - **Channel 2**: Classic Cinema - A black-and-white film with walking silhouette
   - **Channel 3**: BOOM! - The TV explodes in a spectacular finale

## ✨ Features

- **Authentic CRT effects**: Scanlines, screen glow, and subtle flicker animations
- **Pixel art aesthetic**: Blocky retro graphics with limited color palette
- **Smooth animations**: Canvas-based rendering with `requestAnimationFrame`
- **Interactive remote**: Glowing button with hover effects
- **Channel animations**:
  - Boxing match with bouncing fighters
  - Walking character in film-grain movie scene
  - Explosive particle system finale

## 🎨 Design

- Dark gradient background (#111 → #222)
- Retro monospace font (Press Start 2P from Google Fonts)
- CRT TV with decorative knobs and vents
- Authentic scanline overlay effect
- Smooth channel transition flashes

## 🛠️ Technical Details

- Pure vanilla JavaScript (no frameworks)
- HTML5 Canvas for all animations
- CSS3 for styling and CRT effects
- Responsive animations at 60fps
- Pixel-perfect rendering

## 📁 Files

- `index.html` - Main HTML structure
- `style.css` - All styling and visual effects
- `script.js` - Animation engine and channel logic
